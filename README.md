# Sifou Phone — متجر الهواتف والإكسسوارات

متجر إلكتروني كامل باللغة العربية للهواتف والإكسسوارات، مع **الدفع عند الاستلام فقط**
و**لوحة تحكم للمالك** لإضافة المنتجات واستقبال الطلبات.

## المميزات

**واجهة المتجر**
- صفحة رئيسية، صفحة كل المنتجات مع البحث والأقسام والترتيب.
- **صفحة هبوط لكل منتج** (`/p/اسم-المنتج`) فيها استمارة الطلب مباشرة: الاسم، الهاتف، الولاية، البلدية، التوصيل للمنزل أو للمكتب، الخيارات (اللون...)، الكمية، وحساب المجموع مع سعر التوصيل فوراً.
- سلة مشتريات لطلب عدة منتجات مرة واحدة.
- الولايات الـ69 (التقسيم الإداري الجديد 2026) مع أسعار توصيل قابلة للتعديل (منزل / مكتب)، وخيار توصيل مجاني لمنتج معيّن.
- **اللغة الفرنسية**: زر بجانب السلة يحوّل المتجر بالكامل إلى الفرنسية (مع حقول فرنسية اختيارية لكل منتج وقسم).
- صفحة شكر بعد الطلب، زر واتساب عائم، سياسة التوصيل والإرجاع.
- تصميم متجاوب للهاتف مع زر «اطلب الآن» ثابت أسفل الشاشة.
- حماية من الطلبات الوهمية: التحقق من رقم الهاتف الجزائري، منع تكرار نفس الطلب، حد لعدد الطلبات، وحقل خفي ضد البوتات.
- الأسعار تُحسب دائماً في الخادم (لا يمكن التلاعب بها من المتصفح).
- دعم **Facebook Pixel** (ViewContent, AddToCart, InitiateCheckout, Purchase) و sitemap.xml.

**لوحة التحكم** (`/admin`)
- إحصائيات: طلبات اليوم، الطلبات الجديدة، قيد التوصيل، المبيعات، نسبة التسليم، الأكثر مبيعاً، المخزون المنخفض، ورسم بياني لـ14 يوماً.
- إدارة الطلبات: فلترة حسب الحالة (جديد، لا يرد، مؤكد، قيد التوصيل، تم التسليم، ملغى، مرتجع)، بحث بالهاتف أو الاسم، سجل الحالات، ملاحظات داخلية، طباعة وصل، اتصال وواتساب بضغطة، تصدير Excel (CSV).
- المخزون يُخصم تلقائياً عند الطلب ويُعاد عند الإلغاء أو الإرجاع.
- إضافة وتعديل المنتجات: صور متعددة، سعر قبل التخفيض، مخزون، خيارات، مميزات، إخفاء/إظهار.
- الأقسام، أسعار التوصيل لكل ولاية، إعدادات المتجر، تغيير كلمة المرور.
- **تنبيه فوري بالطلبات الجديدة**: صوت وإشعار داخل اللوحة، وإشعار على **تيليغرام** إلى هاتفك.

## التشغيل محلياً

1. ثبّت **Node.js 22.13 أو أحدث** من https://nodejs.org (اختر نسخة LTS). تحقق بالأمر: `node -v`
2. افتح الطرفية **داخل مجلد المشروع** (المجلد الذي فيه `package.json`) ونفّذ:

```bash
npm install
npm start
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin — كلمة المرور الافتراضية `admin123` (غيّرها من الإعدادات).

**لتحديد كلمة المرور أو المنفذ** (يعمل على Windows و Mac و Linux): انسخ الملف `.env.example`
إلى ملف جديد اسمه `.env` وعدّل القيم فيه، ثم أعد تشغيل `npm start`.

يبدأ المتجر بمنتجات تجريبية يمكنك حذفها، أو ضع `SEED_DEMO=0` في `.env` قبل أول تشغيل لمتجر فارغ.

### حل المشاكل الشائعة

| الخطأ | الحل |
|---|---|
| `يتطلب Node.js 22.13 أو أحدث` أو `Cannot find module 'node:sqlite'` | حدّث Node.js من nodejs.org ثم أعد `npm install` |
| `npm error enoent Could not read package.json` | أنت لست داخل مجلد المشروع: `cd Store` ثم أعد الأمر |
| `EADDRINUSE: address already in use` | المنفذ مستعمل: غيّر `PORT` في `.env` (مثلاً 3001) |
| `'ADMIN_PASSWORD' is not recognized` (Windows) | لا تكتب المتغيرات قبل الأمر؛ ضعها في ملف `.env` |

## أول خطوات بعد التشغيل

1. ادخل إلى `/admin` وغيّر كلمة المرور من **الإعدادات**.
2. أدخل رقم الهاتف، واتساب، وروابط فيسبوك/إنستغرام.
3. عدّل **أسعار التوصيل** حسب شركة التوصيل التي تتعامل معها.
4. احذف المنتجات التجريبية وأضف منتجاتك بصورها.
5. (اختياري) اربط **تيليغرام** لتصلك الطلبات على هاتفك، وأضف **Facebook Pixel ID** لإعلاناتك.
6. استعمل رابط صفحة المنتج (`/p/...`) في إعلانات فيسبوك وتيك توك كصفحة هبوط.

## النشر على الإنترنت

المتجر خادم Node.js واحد. البيانات (قاعدة البيانات والصور) تُحفظ في المجلد `DATA_DIR`،
لذلك يجب أن يكون هذا المجلد **دائماً** (persistent disk) وأن تأخذ منه نسخة احتياطية.

**مجاناً بالكامل: Render + Turso (بلا بطاقة بنكية وبلا أوامر)**

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/sifou-phone/Store)

1. **Turso** (قاعدة البيانات): سجّل في turso.tech بحساب GitHub ← Create Database (اختر منطقة أوروبية)
   ← انسخ رابط القاعدة (`libsql://...`) ثم أنشئ Token وانسخه.
2. **Render** (تشغيل المتجر): اضغط زر Deploy to Render أعلاه ← سجّل بحساب GitHub ← الصق:
   `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN` و `ADMIN_PASSWORD` ← Apply.
   بعد بضع دقائق يعمل المتجر على رابط مثل `https://sifou-phone-store.onrender.com`.
3. **UptimeRobot** (لإبقائه مستيقظاً): الخطة المجانية في Render تنام بعد 15 دقيقة بلا زيارات.
   سجّل في uptimerobot.com ← Add New Monitor ← HTTP(s) ← الرابط `https://…onrender.com/healthz` ← كل 5 دقائق.

الطلبات والمنتجات والصور كلها تُحفظ في Turso، لذلك لا يضيع شيء عند إعادة تشغيل Render.
الصور تُصغَّر تلقائياً في المتصفح قبل رفعها.

**الأرخص: خادم VPS بأمر واحد (يعمل على Ubuntu أو Debian — مثل RackNerd أو Hetzner أو Oracle):**
ادخل إلى الخادم عبر SSH ثم نفّذ:
```bash
curl -fsSL https://raw.githubusercontent.com/sifou-phone/Store/claude/brave-clarke-0wubdq/deploy/install.sh | sudo bash
```
يثبّت السكربت Node.js، ويشغّل المتجر كخدمة تعيد التشغيل تلقائياً، ويضع خادم Caddy أمامه،
ويأخذ نسخة احتياطية يومية في `/var/backups/sifou-store`، ويطبع في النهاية الرابط وكلمة مرور لوحة التحكم.
- مع نطاقك الخاص (شهادة HTTPS تلقائية): وجّه سجل `A` للنطاق إلى عنوان IP الخادم ثم أضف النطاق في آخر الأمر:
  `... | sudo bash -s -- sifouphone.com`
- للتحديث لاحقاً: أعد نفس الأمر (البيانات تبقى كما هي).

**Docker (أي خادم VPS):**
```bash
docker build -t sifou-store .
docker run -d --name sifou -p 3000:3000 -v sifou-data:/data \
  -e ADMIN_PASSWORD=كلمة-سر-قوية --restart unless-stopped sifou-store
```
ثم ضع أمامه Nginx أو Caddy مع شهادة HTTPS لنطاقك.

**Railway (الأسهل):** New Project ← Deploy from GitHub repo ← اختر هذا المستودع.
ثم أضف Volume واجعل مساره `/data`، وأضف المتغيرين `DATA_DIR=/data` و `ADMIN_PASSWORD`،
ثم من Settings ← Networking اضغط Generate Domain (أو اربط نطاقك).

**Render / Fly.io:** اربط هذا المستودع، أمر التشغيل `npm start`،
أضف قرصاً دائماً (Disk / Volume) واجعل `DATA_DIR` يشير إليه، وحدد `ADMIN_PASSWORD`.

**النسخ الاحتياطي:** يكفي نسخ المجلد `DATA_DIR` (الملف `store.db` ومجلد `uploads`).

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3000` |
| `ADMIN_PASSWORD` | كلمة المرور عند أول تشغيل | `admin123` |
| `DATA_DIR` | مجلد قاعدة البيانات والصور | `./data` |
| `SEED_DEMO` | `0` لعدم إضافة المنتجات التجريبية | `1` |
| `SESSION_SECRET` | مفتاح توقيع الجلسات (يُولَّد تلقائياً إن لم يُحدد) | — |
| `TURSO_DATABASE_URL` | رابط قاعدة Turso (`libsql://…`) لحفظ البيانات خارج الخادم | — |
| `TURSO_AUTH_TOKEN` | مفتاح الوصول لقاعدة Turso | — |
| `TRUST_PROXY` | `0` إذا لم يكن الخادم خلف proxy | `1` |
| `HOST` | عنوان الاستماع (`127.0.0.1` خلف proxy) | كل العناوين |
